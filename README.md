# MPKMod 26.1 — No Red Glow

A custom build of [MPKMod2](https://github.com/MPKMod/MPKMod2) for **Minecraft 26.1 (Fabric)**.

This build changes one thing from the original: the **red glow on selected landing blocks is made fully transparent** (hidden). The green highlight state still works as normal.

## How to Use

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft **26.1**.
2. Download [Fabric API](https://modrinth.com/mod/fabric-api) for 26.1 and place it in your `mods` folder.
3. Download `mpkmod-2.3.2-fabric-26.1.jar` from this repo and place it in your `mods` folder.
4. Launch the Fabric profile.
