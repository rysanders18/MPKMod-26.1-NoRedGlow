# MPKMod 26.1 — Minr Friendly, No Red Glow

A custom build of [MPKMod2](https://github.com/MPKMod/MPKMod2) for **Minecraft 26.1 (Fabric)**, set up to work on **Minr**.

Two changes from the public build:
- **Whitelisted for Minr** — uses the `minr_mpkmod2:network` channel so the Minr server accepts the client.
- **No red glow** — the red highlight on selected landing blocks is fully transparent (hidden). The green highlight still works.

## How to Use

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft **26.1**.
2. Download [Fabric API](https://modrinth.com/mod/fabric-api) for 26.1 and place it in your `mods` folder.
3. Download `minr-mpkmod-2.3.2-fabric-26.1.jar` from this repo and place it in your `mods` folder.
4. Launch the Fabric profile.
